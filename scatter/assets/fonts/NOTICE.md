# Font sources

- Pretendard Regular / Medium / SemiBold: 로컬의 기존 프로젝트에 있던 동일 폰트 파일을 복사해 사용. Pretendard는 SIL Open Font License 1.1 배포: https://github.com/orioncactus/pretendard
- Alien Encounters Regular / ShyFonts: Figma가 지정한 로고 폰트. https://www.dafont.com/alien-encounters.font 에서 받은 원본 zip과 TTF를 보관. 해당 배포 페이지에 Free for personal use로 표시되어 있어 이 로컬 과제 구현에 사용. 상업적 배포 시 해당 글꼴의 이용 허락을 확인해야 함.
